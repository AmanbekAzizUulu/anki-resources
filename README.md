# Anki Resources

A collection of images, GIFs, and other static assets used in my Anki projects.

This repository serves as a central storage for resources displayed in AnkiWeb deck descriptions, documentation, and related materials.

## Repository Structure

```text
images/
├── german-verbs/
├── german-nouns/
├── dentistry/
└── ...
```

## Purpose

The assets in this repository are used to:

- illustrate Anki deck descriptions on AnkiWeb;
- demonstrate card layouts and features;
- store screenshots, GIFs, icons, and other media;
- provide shared resources across multiple Anki projects.
